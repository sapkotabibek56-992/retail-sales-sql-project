# Retail Sales SQL Project

## Project Overview

This project is a retail sales database built using PostgreSQL. It contains SQL queries for analyzing customers, products, employees, stores, and orders.

The project includes basic SQL, aggregations, joins, business analysis, subqueries, Common Table Expressions (CTEs), CASE expressions, and window functions.
